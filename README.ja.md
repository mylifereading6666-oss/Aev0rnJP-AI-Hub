# Aev0rnJP AI Hub

**日本語版ドキュメント** | [English](README.en.md)

Aev0rnJP AI Hub は、スマートフォンと PC の両方で使える、ダークテーマのブラウザー向け AI ツールです。GitHub Pages で公開できる静的 Web アプリとして構成されています。

## 主な機能

- **AI チャット**：対応ブラウザーでは WebGPU を利用し、ブラウザー内で AI モデルを実行します。
- **コード作成・編集**：コードを書いたり、編集したり、コピーまたはファイルとして保存したりできます。
- **ファイル解析**：テキストファイルや対応する PDF の内容を読み込めます。
- **Web 検索**：外部検索サービスを開いて情報を探せます。
- **レスポンシブ表示**：スマートフォンと PC の画面に対応します。
- **PWA 対応**：対応ブラウザーではアプリとしてのインストールを利用できます。
- **チャット履歴**：対応ブラウザーのローカルストレージに履歴を保存します。

## 公開方法（GitHub Pages）

1. このリポジトリを GitHub で開きます。
2. **Settings → Pages** に進みます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. Branch を `main`、フォルダーを `/(root)` に設定して **Save** を押します。
5. デプロイが完了したら、Pages 設定画面に表示される公開 URL を開きます。

## 使い方

1. 公開サイトを対応ブラウザーで開きます。
2. AI チャットを使う場合はモデルを選択し、初回のモデルダウンロードが終わるまで待ちます。
3. コード作成、ファイル解析、Web 検索などは画面上の各タブから利用します。

## 注意事項と制限

- **AI の動作には対応環境が必要です。** WebGPU に対応していないブラウザーや端末では、AI チャットが動作しない場合があります。
- **初回はモデルのダウンロードが必要です。** モデルのサイズ、端末のメモリー、GPU 性能、通信環境によって、起動に時間がかかったり、動作しなかったりする場合があります。
- **完全なオフライン動作ではありません。** AI モデルやライブラリーの初回取得などにインターネット接続が必要です。キャッシュ済みの画面が開けても、すべての機能がオフラインで使えるとは限りません。
- **Web 検索は検索サービスを開く機能です。** アプリが検索結果を自動で取得・要約する仕組みではありません。
- **コード実行環境ではありません。** コードの作成・編集・保存はできますが、サイト内でコードを安全に実行する機能はありません。
- **画像生成機能はありません。**
- AI の回答は誤ることがあります。重要な情報やコードは必ず確認してください。
- チャット履歴は使用中のブラウザーのローカルストレージに保存されます。共有端末では注意してください。
